Windows Server Home Lab

Active Directory • DNS • DHCP • Hyper-V • Enterprise Networking

Description

  • This project demonstrates the setup of a Windows Server 2025 Home Lab that simulates a small enterprise network environment.
  • It includes the installation and configuration of Active Directory, DNS, and DHCP services, along with a Windows client joined to a domain.
  • The goal of this project is to develop hands-on skills in Windows Server administration, network infrastructure setup, and enterprise IT operations.

Implementation Steps

1. Create Virtual Machines

Two virtual machines were created to simulate a basic enterprise environment.

SRV-DC01

Windows Server 2025 used as the Domain Controller.

PC-01

Windows 10 / 11 client machine joined to the domain.

2. Install Windows Server 2025

  • Windows Server 2025 was installed on the SRV-DC01 virtual machine.
  • The server was renamed to SRV-DC01 for proper network identification.
Watch on YouTube

3. Post-Installation Tasks

  • After installing Windows Server 2025, several post-installation configurations were performed to prepare the server for a production-like deployment.
  • These tasks ensure proper network communication, remote management capability, and system readiness before deploying Active Directory services.

Configure Computer Name

The server hostname was renamed to SRV-DC01 for proper identification within the network environment.

Set Static IP Address

A static IP address was configured to ensure consistent network communication for Active Directory, DNS, and DHCP services.

Configure Time Zone

The server time zone was configured to ensure accurate logging, authentication, and scheduled tasks.

Enable Remote Desktop

Remote Desktop was enabled to allow remote administration and management of the server environment.

Run Windows Updates

Windows updates were installed to improve system stability, security, and performance.

4.1. Deploy Active Directory Domain Services (AD DS) and DNS

  • The Active Directory Domain Services (AD DS) role was installed and configured to enable domain controller functionality.
  • During the domain controller promotion process, the DNS Server role was automatically installed and configured to support domain name resolution within the Active Directory environment.
  • Domain: csenterprise.local
  • This configuration enables centralized management of users, computers, authentication, and network resources.
Watch on YouTube

4.2. Basic Active Directory Domain Services (AD DS) Administration

  • Basic Active Directory administration tasks were performed to simulate user and resource management in an enterprise environment.
  • These tasks include managing users, groups, organizational units, and security policies within the domain.

Manage Organizational Units

Organizational Units (OUs) were created to organize users and resources within Active Directory.

Create User Accounts

User accounts were created to allow authentication and access to domain resources.

Reset Passwords

Passwords were reset to restore account access and maintain security.

Unlock User Accounts

Locked user accounts were unlocked after failed sign-in attempts.

Disable or Delete Accounts

Unused accounts were disabled or deleted to improve account management and security.

Create Security Groups

Security groups were created to simplify permission and access management.

Add Users to Groups

Users were added to groups to assign permissions and resource access.

Assign Permissions

Permissions were assigned to control access to shared resources and folders.

Password Policy

Password policies were configured to enforce password complexity and security requirements.

Account Lockout Policy

Account lockout policies were configured to protect the environment from unauthorized access attempts.

5. Deploy & Administer DHCP

  • The DHCP Server role was installed and configured to automatically assign IP addresses to client devices within the network environment.
  • Basic DHCP administration tasks were performed to simulate enterprise network management and automated client configuration.
Watch on YouTube

5.1. Test DHCP Client Connectivity

Join PC Client to DHCP Server

The client computer was configured to obtain an IP address automatically from the DHCP server.

Test PC Client Connectivity

Network connectivity tests were performed to verify successful DHCP configuration and communication between devices.
