Common Troubleshooting Issues

This section demonstrates common Windows Server, Active Directory, DNS, DHCP, and networking issues encountered during the Windows Server Home Lab project, including investigation procedures and resolution steps.

Trust Relationship Between Workstation and Domain Failed

Error Message:

“The trust relationship between this workstation and the primary domain failed.”

Investigation

  • Verified network connectivity between the client workstation and the Domain Controller
  • Checked whether the client machine could communicate with the DNS server
  • Confirmed the workstation was still joined to the domain
  • Tested domain connectivity using the computer name and domain credentials
  • Reviewed the computer account status in Active Directory Users and Computers (ADUC)
  • Verified date and time synchronization between the client and the Domain Controller
  • Attempted to log in using a domain user account to reproduce the issue

Resolution Steps

  • Logged in using the local administrator account
  • Removed the workstation from the domain
  • Joined the workstation to a temporary workgroup
  • Restarted the client computer
  • Rejoined the workstation to the Active Directory domain
  • Restarted the workstation again
  • Verified successful domain authentication

The RPC Server Is Unavailable

Error Message:

“The RPC server is unavailable.”

Investigation

  • Tested network communication between the client and server
  • Verified DNS name resolution
  • Checked Windows Firewall settings
  • Verified RPC-related services were running
  • Tested connectivity using ping and nslookup commands
  • Checked whether remote management ports were accessible

Resolution Steps

  • Started required RPC services
  • Allowed RPC traffic through Windows Firewall
  • Verified correct DNS server configuration
  • Restarted affected systems
  • Retested remote communication successfully

Domain Controller Could Not Be Contacted

Error Message:

“An Active Directory Domain Controller (AD DC) for the domain could not be contacted.”

Investigation

  • Checked DNS configuration on the client machine
  • Verified connectivity to the Domain Controller
  • Tested domain name resolution using nslookup
  • Checked Active Directory and DNS services
  • Verified network adapter settings
  • Tested communication using ping commands

Resolution Steps

  • Configured the correct DNS server IP address
  • Restarted networking services
  • Verified Active Directory communication
  • Successfully joined the workstation to the domain

DNS_PROBE_FINISHED_NXDOMAIN

Error Message:

“DNS_PROBE_FINISHED_NXDOMAIN”

Investigation

  • Tested DNS name resolution
  • Checked DNS zone records
  • Verified DNS client configuration
  • Tested internal resource accessibility
  • Reviewed DNS forward lookup zones
  • Verified DNS server communication

Resolution Steps

  • Corrected DNS server configuration
  • Created missing DNS records
  • Cleared DNS cache using ipconfig /flushdns
  • Retested internal resource access

Client Receives an APIPA Address

Error Message:

Client receives an APIPA address (169.254.x.x) instead of a DHCP IP.

Investigation

  • Verified DHCP Server service status
  • Checked DHCP scope availability
  • Tested network adapter configuration
  • Verified physical and virtual network connectivity
  • Checked whether the client was configured to obtain an IP address automatically
  • Verified DHCP authorization in Active Directory

Resolution Steps

  • Restarted DHCP services
  • Renewed the client IP address
  • Verified DHCP scope activation
  • Confirmed successful DHCP lease assignment

Windows Could Not Obtain an IP Address

Error Message:

“Windows could not obtain an IP address from the DHCP Server.”

Investigation

  • Verified DHCP scope configuration
  • Checked DHCP authorization status
  • Verified network adapter settings
  • Tested communication with the DHCP server
  • Checked for available IP addresses in the scope
  • Reviewed DHCP service status

Resolution Steps

  • Restarted DHCP services
  • Activated the DHCP scope
  • Renewed the client IP address
  • Verified successful DHCP assignment

  • Checked client network settings

Resolution Steps

  • Released and renewed client IP configuration
  • Corrected duplicate static IP settings
  • Updated DHCP exclusions and reservations
  • Confirmed unique IP assignment
