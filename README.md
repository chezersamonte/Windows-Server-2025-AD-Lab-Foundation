# Windows Server Infrastructure Services Lab

A hands-on Windows Server 2025 Home Lab designed to simulate a small enterprise network environment. This project demonstrates real-world Windows Server administration by configuring core infrastructure services, managing Active Directory, and administering domain-joined client computers.

## Live Website

🌐 **View the lab here:**

## Overview

This home lab was built using Hyper-V virtual machines to replicate a basic enterprise infrastructure. It provides practical experience with Windows Server administration, networking, identity management, and troubleshooting through hands-on configuration and real-world administrative tasks.

The project is intended to develop the foundational skills required for Help Desk, IT Support, System Administrator, and Windows Server Administrator roles.

## Project Purpose

The goal of this repository is to build practical Windows Server administration skills through hands-on labs that simulate a real enterprise environment.

This project documents the complete implementation process, including server installation, infrastructure configuration, client deployment, administration tasks, troubleshooting, screenshots, and video demonstrations. It also serves as a technical portfolio showcasing my Windows Server, Active Directory, networking, and IT infrastructure skills to recruiters and hiring managers.
