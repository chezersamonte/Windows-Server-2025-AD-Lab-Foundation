## Project Overview

This project is a Windows Server 2025 Home Lab designed to simulate a small enterprise network environment. It demonstrates real-world server administration tasks such as configuring Active Directory, DNS, and DHCP, along with managing domain-joined client machines.

The lab was built using Hyper-V virtual machines to replicate a basic enterprise infrastructure, helping develop practical skills in Windows Server management, networking, and troubleshooting.
